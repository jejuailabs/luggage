# 12. 사업 준비 확인 목록 — 보험·운송 자격·원가·고객 확보

연결: [메인](../AGENTS.md), [예약·결제·정산](06-booking-payments-settlement.md), [물류·운영](07-logistics-tracking-operations.md), [유입·지표](08-china-acquisition-analytics.md)

코드로 해결되지 않는 출시 전 결정 사항이다. 법률·보험 항목은 전문가(행정사·노무/법무·보험 중개사) 확인이 필요하며, 아래는 확인할 질문과 제품 설정에 미치는 영향을 정리한 것이다. 확인 결과는 이 문서와 필수 안내 버전에 반영한다.

## 1. 보험 (조언 4)

| 확인할 것 | 제품에 미치는 영향 |
|---|---|
| 적재물배상책임보험 가입 의무 대상인지, 가입 한도(1건·1사고·연간) | 필수 안내 ‘파손·분실 보상 기준’의 짐 1개당 50만 원 한도와 맞아야 한다. 한도가 다르면 안내 버전을 올려 재게시 |
| 고객 짐 보관 중(호텔 프런트 대기) 손해가 보험 범위에 들어가는지, 호텔 책임과 구분 | 호텔 제휴 계약의 책임 조항, 인계 사진 기록 시점(`bag_events`) |
| 항공편 지연 손해(변경 수수료) 보상 가능 여부 | 안내의 1명당 20만 원 한도 유지 또는 삭제 |
| 보험사 청구에 필요한 증빙 | 인계 사진 보존 기간(현재 180일, 사고 처리 중이면 해결 시까지)과 사고 기록 항목 |

## 2. 운송 자격·위탁 (조언 5)

| 확인할 것 | 제품에 미치는 영향 |
|---|---|
| 직접 차량 운행 시 필요한 화물 운송 사업 허가 종류와 차량 요건 | 기사·차량 등록(`vehicles`), 업무 계정 발급 기준 |
| 운송을 외부 업체에 위탁할 경우 상대 업체의 허가·보험 확인과 위탁 계약서 | 기사 계정을 위탁 업체 소속으로 발급, 정산 대상 추가 여부 |
| 유상 운송 시 차량 표시·번호판 요건 | 기사 앱의 차량 지정, 고객 화면의 차량 표시 문구 |
| 개인정보 처리 위탁(기사·호텔에 이름 표시) 고지 | 개인정보 처리방침, 기사·호텔에 최소 정보만 노출하는 현재 RLS 유지 |

## 3. 원가 구조 결정 (조언 1)

| 방식 | 장점 | 단점 | 제품 설정 |
|---|---|---|---|
| **배치 운송** (정해진 시간대에 권역별로 모아 운행) | 1건당 원가 낮음, 차량·기사 계획이 쉬움, 공항 인계를 한 장소·시간대로 묶기 쉬움 | 고객 선택 시간이 제한됨 | 현재 구조와 같다: `service_slots`(수거·인계 창)·`capacity_buckets`(차량 적재 단위) |
| **개별 호출** (주문마다 바로 배차) | 시간 선택 자유, 고가 요금 가능 | 1건당 원가 높음, 수요가 적을 때 손실 | 슬롯 대신 즉시 배차·거리 기반 요금이 필요 (추가 개발) |

**추천:** 배치 운송으로 시작한다. 이미 구현된 슬롯·용량 구조를 그대로 쓰고, 권역(제주시·서귀포)별 하루 2~3회 운행으로 원가를 확인한 뒤 수요가 큰 시간대만 슬롯을 늘린다. 결정할 값: 운행 회차, 차량당 적재 단위(`capacity_buckets.max_units`, 보통 1·대형 2 단위), 노선별 요금(`price_rules`).

## 4. 고객 확보 경로 결정 (조언 2)

| 경로 | 제품에 이미 있는 것 | 결정할 것 |
|---|---|---|
| 호텔 제휴 QR (프런트·객실 포스터) | 제휴 코드·유입 귀속·수수료·QR 포스터(`/partner/qr`) | 제휴 숙소 목록, 수수료율, 포스터 배치 |
| 샤오홍슈·위챗 콘텐츠 | 캠페인 링크 기록(`/admin/campaigns`), 상황별 안내 3종 | 운영 계정, 게시 주기 |
| 위챗 미니프로그램 | 하이브리드 셸(mock) | AppID·위챗페이 가맹 |
| OTA·액티비티 플랫폼 입점 (예: 중국어권 여행 예약 앱) | 없음 | 입점 여부, 판매 수수료, 예약 연동 방식 |

**추천:** 초기에는 호텔 제휴 QR을 주 경로로 한다. 짐을 맡기는 장소가 호텔 프런트라 전환이 가장 직접적이고, 귀속·수수료 기능이 이미 있다. 콘텐츠·미니프로그램은 제휴 숙소가 확보된 권역부터 확장한다.

## 5. 제휴 숙소 목록 (보완점 4)

- 확보한 숙소는 운영자가 `/admin/hotels`에 등록하고 노선을 연결하면 검색 결과에 ‘제휴 · 바로 예약’으로 표시되고 즉시 예약이 열린다.
- 등록 전 숙소는 관광공사 목록에서 검색돼 견적 문의로 접수된다.
