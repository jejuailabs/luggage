## 우선 해결 순서

1. **실서비스 기반 연결:** 호텔 API 503과 익명 로그인 503은 해결했다. 실제 승인 안내 게시, 고객·호텔·기사·운영자 계정과 Storage 실기 검증을 진행한다.
2. **예약 완주:** 실제 승인된 정책·가격·슬롯·공항 인계 장소를 운영자가 입력할 수 있게 하고, 견적→주문→결제→예약증→수거→인계→조회가 한 계정에서 이어지는지 검증한다.
3. **거래·현장 운영:** 실제 PG, 환불 승인·확인 큐, 고객 알림, 반환·정정, 태그 인쇄, 직원 MFA와 권한 검증을 완성한다.
4. **출시 검증:** 위챗·알리페이 실결제, PWA 카메라·오프라인·푸시, 중국망 접속, 차량 단말 위치, 백업·복구와 성능을 실기기·운영 환경에서 검증한다.
